Welcome to MicroCode

Developer Preview · Version 2.0.1 (Build 2)

MicroCode is a native macOS workspace from Dotmini Software for AI-assisted coding, local terminals, notebooks, device previews, and project automation.

Preview release
This build is intended for invited developers to evaluate features and report issues. It is not a production release.

Installation

  • MicroCode will be installed in /Applications.
  • macOS 13 or later is required.
  • Some features use locally installed developer tools, such as Xcode, Node.js, Flutter, Android SDKs, or language runtimes.
